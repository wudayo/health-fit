    📏围度趋势（腰 / 臂 / 臀）

    围度比体重更反映「瘦胖」改善，每周量 2–3 次即可

    测量时机固定（如晨起空腹）：腰围量肚脐上 1 指，臂围量肱二头肌最粗处，臀围量最宽处。

    🤖AI 拍照识别设置

    接入视觉模型后，三餐可直接拍照自动识别食物与热量。Key 仅存本机，不上传服务器。

    ⚠️ 浏览器直连需服务商允许跨域（CORS）。OpenAI 默认禁止浏览器调用，建议用支持 CORS 的国内视觉模型（通义千问 / 智谱 / Kimi / 豆包 / 硅基流动 DeepSeek-VL2 均可）。若调用失败，多为 CORS 或 Key 问题。识别结果仅供参考，热量以估算为准。

    ☁️云同步（手机/电脑通用）

    把档案与打卡记录同步到云端，手机和电脑打开同一份数据。AI Key 不同步（各设备独立）。

    GitHub 方式：github.com → Settings → Developer settings → Personal access tokens，生成带 gist 权限的令牌粘这里即可。数据存为你的私有 Gist，仅你可见。自定义方式需你自建一个接受 GET/PUT JSON 的接口。
